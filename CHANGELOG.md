# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Modern Python 3.13 support with full type annotations
- Comprehensive project structure with proper package layout
- Pre-commit hooks for code quality enforcement
- Strict MyPy configuration for type safety
- Enhanced Ruff linting with additional rule sets
- Test infrastructure with pytest and fixtures
- MIT License
- Project metadata in pyproject.toml

### Changed
- Updated Python requirement from 3.12 to 3.13
- Enhanced linting configuration with more strict rules
- Improved type safety with stricter MyPy settings

### Security
- Added Bandit security linting in pre-commit hooks
- Added detection for private keys in commits

## [0.1.0] - 2025-01-22

### Added
- Initial project setup
- Basic directory structure
- Project roadmap and milestones
- Setup and verification scripts
- Configuration for modern Python development tools
- Documentation structure
