🔍 Inside the Neural Network

How Your Drawing Flows Through the Network

This visualization shows the complete journey of how your drawing is processed:
• Top: The flow of information from input to final prediction
• Middle: Which features were most important at each layer
• Bottom: The final decision and why the network chose this digit

Layer 1: Edge Detection

Purpose: Detects basic edges and strokes

Filters: 32

Output size: 28×28

The first convolutional layer learns to detect simple patterns like edges, corners, and basic strokes. Each square shows what one filter "sees" in your drawing.

Layer 2: Shape Detection

Purpose: Combines edges into shapes

Filters: 64

Output size: 14×14

The second layer combines simple patterns from Layer 1 to detect more complex shapes like curves, loops, and intersections that are common in digits.

Layer 3: Digit Features

Purpose: Recognizes digit-specific patterns

Filters: 128

Output size: 7×7

The third layer has learned to recognize features specific to each digit, like the closed loop of 0, the vertical line of 1, or the curves of 3.

📚 How It Works

1. Input Processing

Your drawing is converted to a 28×28 pixel grayscale image, matching the format the model was trained on.

2. Feature Extraction

Convolutional layers scan the image with learned filters, detecting increasingly complex patterns at each layer.

3. Classification

The final layers combine all detected features to determine which digit (0-9) best matches the input.

4. Confidence Score

The model outputs probabilities for each digit. Higher confidence means the model is more certain of its prediction.

Understanding the Neural Network Visualizer

How to Use

  1. Draw a digit (0-9) on the canvas using your mouse or touchpad
  2. Click "Predict" to see the AI's prediction
  3. Explore the visualizations to understand how the AI made its decision

Understanding the Layers

🔵 Layer 1: Edge Detection

The first layer learns to detect simple features like edges and strokes. Think of it as breaking down your drawing into basic lines and curves.

🟢 Layer 2: Shape Recognition

The second layer combines edges to recognize shapes. It might detect "loops" for 0, 6, 8, 9 or "vertical lines" for 1, 4, 7.

🟠 Layer 3: Digit Features

The third layer recognizes complete digit patterns. Each filter has specialized in detecting specific digits or digit combinations.

Reading the Visualizations

  • Brighter areas in feature maps indicate stronger activations
  • Probability chart shows the model's confidence for each digit
  • Summary view shows overall activity in each layer

Tips for Best Results

  • Draw digits clearly and centered
  • Use smooth, continuous strokes
  • Make digits fill most of the canvas
  • Try different writing styles to see how the model adapts
